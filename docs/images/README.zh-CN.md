# 截图说明

[English](README.md) | **简体中文** | [Deutsch](README.de-DE.md) | [日本語](README.ja-JP.md)

英文（`*-en.jpg`）和中文（`*-zh.jpg`）截图拍摄于 2026 年 11 月 18 日；德文（`*-de.jpg`）和日文（`*-ja.jpg`）截图拍摄于 2026 年 11 月 23 日。截图来自实际运行的前端与标注 iframe，通过界面的语言选择框切换语言，图片未做后期修改。

德文与日文截图使用独立的本地文档站点 `http://127.0.0.1:4194`，标注服务运行在 4195 端口，账户 API 在 4197 端口使用空的临时数据库。没有读取已有任务或账号。编辑器显示游客状态，未发送登录邮件、投递导出结果或创建存储连接。

图片界面使用内置的 `public/examples/street.svg`。导入预览通过向界面粘贴包含两条数据的 `PublicAnnotationInput` JSON 创建，引用文档站点上的 `entities.de-DE.txt` 或 `entities.ja-JP.txt`，以及 `street.pcd`。任务通过同一窗口实际创建。日文任务列表用“サンプル”搜索，只显示对应的两条示例任务。

原有中英文导入图使用本地 `entities.txt` 和 `street.pcd` 文件。所有图片都不含账号凭证或存储密钥。导出地址 `https://example.com/api/tasks/{taskId}/annotations` 仅为示例，未向其发送数据；存储表单的凭证栏保持为空。
