# スクリーンショットについて

[English](README.md) | [简体中文](README.zh-CN.md) | [Deutsch](README.de-DE.md) | **日本語**

英語版（`*-en.jpg`）と中国語版（`*-zh.jpg`）は 2026 年 11 月 18 日、ドイツ語版（`*-de.jpg`）と日本語版（`*-ja.jpg`）は 2026 年 11 月 23 日に撮影しました。すべて動作中のアプリで言語を切り替えて撮影した、未加工のブラウザースクリーンショットです。

ドイツ語版と日本語版では、撮影専用の Origin `http://127.0.0.1:4194` を使用しました。実際のアノテーションサービスはポート 4195、空の一時データベースを使うアカウント API はポート 4197 です。既存のタスクやアカウントは使用せず、エディターはゲスト状態で表示しています。ログインメールの送信、エクスポートの送信、ストレージ接続の作成は行っていません。

画像の画面は `public/examples/street.svg` を使っています。インポートのプレビューは、2 件のレコードを含む `PublicAnnotationInput` JSON を画面へ貼り付けて作成しました。参照先は、付属の `entities.de-DE.txt` または `entities.ja-JP.txt` と `street.pcd` です。撮影用 Origin の HTTP URL で参照し、同じ画面からタスクを作成しました。日本語のタスク一覧は「サンプル」で検索し、該当する 2 件を表示しています。

従来の英語版・中国語版のインポート画面では、ローカルの `entities.txt` と `street.pcd` を使用しています。いずれの言語版にもアカウントやストレージの認証情報は写っていません。エクスポート先の `https://example.com/api/tasks/{taskId}/annotations` は記入例で、この URL への送信は行っていません。ストレージの認証欄は空欄です。

| ファイル           | 画面                                                       |
| ------------------ | ---------------------------------------------------------- |
| `01-start-*.jpg`   | 開始画面とサンプルの選択                                   |
| `02-import-*.jpg`  | 作成前のタスク一覧。ドイツ語版と日本語版は JSON 入力を使用 |
| `03-tasks-*.jpg`   | テキストと点群のサンプルタスク                             |
| `04-tools-*.jpg`   | 画像のツール設定とデータプレビュー                         |
| `05-editor-*.jpg`  | 画像アノテーション                                         |
| `06-export-*.jpg`  | API へのエクスポート設定                                   |
| `07-storage-*.jpg` | 認証情報が未入力のストレージ接続                           |

撮り直す場合は、フロントエンドと実際のサービスを起動し、README の該当する手順で言語を選んでください。画面の読み込み完了後に撮影し、画像は加工せずに使用します。サンプルや操作手順を変えたときは、この説明も更新してください。
